# 纹以载道 · 中国传统纹样数字长卷

中国传统纹样科普展示作品，面向 AIGC 类数字创意作品创作赛项。

## 内容

- `index.html` 入口页
- `deck.html` 竖向长卷（四个纹样 + 在地章节 + 馆藏章节）
- `kiosk.html` 展台版
- `about.html` 创作说明与 AIGC 合规披露
- `real/` `video/` `audio/` `assets/` 素材目录

## 说明

四个纹样：云纹、缠枝莲纹、青铜兽面纹、壮锦几何纹。
「在地」一节将拆解方法用于桂林理工大学地质博物馆藏品。
页面内演示动画为程序化矢量实现（SVG + JavaScript），非 AI 生成。
